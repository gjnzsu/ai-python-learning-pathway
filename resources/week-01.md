# 第 1 周公开资源

本周只安排少量官方资料，先实践，再按需查阅。

## 必读

- [Python 3.12 官方教程：控制流](https://docs.python.org/3.12/tutorial/controlflow.html)：重点阅读函数定义、参数和编码风格。
- [Python 3.12 官方教程：数据结构](https://docs.python.org/3.12/tutorial/datastructures.html)：重点阅读列表、元组和字典。

## 本课查阅

- [Python 3.12 官方教程](https://docs.python.org/3.12/tutorial/index.html)
- [Python 3.12 执行模型](https://docs.python.org/3.12/reference/executionmodel.html)
- [PEP 8：Python 代码风格](https://peps.python.org/pep-0008/)

## 本周稍后使用

- [Python 3.12：错误与异常](https://docs.python.org/3.12/tutorial/errors.html)
- [Python 3.12：虚拟环境与包](https://docs.python.org/3.12/tutorial/venv.html)

## 第 2 课：循环与日志统计

- [Microsoft：Loops | Python for Beginners](https://www.youtube.com/watch?v=LrOAl8vUFHY)：约 6 分钟，介绍 `for` 和 `while` 的适用场景。
- [Microsoft Learn：Demo: Loops](https://learn.microsoft.com/en-us/shows/intro-to-python-development/python-for-beginners-28-of-44-demo-loops)：约 4 分钟，用循环遍历集合的演示。
- [Bilibili：微软 Python 初学者教程（中文字幕）](https://www.bilibili.com/video/BV1aQ4y1d78L/)：可选，只看第 27、28 集。
- [Python 3.12 官方教程：控制流](https://docs.python.org/3.12/tutorial/controlflow.html)：重点查看 `for`、`range` 和 `while`。
- [Python 3.12 官方教程：循环技巧](https://docs.python.org/3.12/tutorial/datastructures.html#looping-techniques)：重点查看字典遍历、`enumerate` 和 `zip`。

建议不要从头到尾通读文档。先完成课程任务，遇到概念时再定位相关章节。
