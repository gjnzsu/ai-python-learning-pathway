# 第二课精简课件设计

## 目标

为具有 Java / Spring Boot 背景、刚开始学习 Python 的学习者提供一节 30–45 分钟的精简课程。课程完成后，学习者能够使用 Python 循环遍历多行日志，以字典统计日志级别，并理解 `while`、`range`、`enumerate` 和 `zip` 的基本用途。

## 教学方式

采用项目驱动方式，以现有日志分析 CLI 的 `count_log_levels()` 行为为主线。语法只在项目需要或对后续学习有帮助时引入，并通过 Java 对照降低语言切换成本。

## 课件结构

1. 约 5 分钟：对照 Java 增强 `for` 与 Python `for`，建立“直接遍历可迭代对象”的心智模型。
2. 约 10 分钟：讲解字典计数、`KeyError` 与 `dict.get(key, default)`。
3. 约 10 分钟：使用 RED → GREEN → REFACTOR 实现和验证 `count_log_levels(lines)`。
4. 约 10 分钟：通过独立短例子认识 `while`、`range`、`enumerate` 和 `zip`，明确各自适用场景。
5. 约 5 分钟：完成小测、运行测试并复盘关键术语。

## 项目行为

新增函数接口：

```python
def count_log_levels(lines: list[str]) -> dict[str, int]:
    ...
```

函数逐行调用现有的 `parse_log_line()`，读取事件的 `level` 字段并累计计数。正常示例 `INFO → ERROR → INFO` 应返回 `{"INFO": 2, "ERROR": 1}`。本课不扩展非法级别、跳过空行或错误恢复逻辑，避免超出精简课范围。

## 错误处理与测试

- 沿用 `parse_log_line()` 已有的 `ValueError` 行为，不在统计函数中捕获或转换异常。
- 使用现有 `unittest` 测试风格。
- 本课至少覆盖一个多行、多级别统计用例。
- 空输入、未知级别和非法日志将在后续测试中按学习进度逐步加入，不提前实现。

## 视频与参考资料

课件包含少量经核验的外部资源：

- 两个约 5 分钟、聚焦循环概念或演示的核心视频，优先使用官方且链接稳定的来源。
- 一个带中文字幕或中文讲解的可选资源。
- Python 3.12 官方教程相关章节，作为查阅资料而非课前通读任务。

视频只辅助理解，不代替项目练习。

- 课件可在 30–45 分钟内完成。
- 示例与当前项目代码、测试命令一致。
- 学习者能解释何时使用 `for`、`while`、`range`、`enumerate` 和 `zip`。
- 学习者能独立完成日志级别统计并使测试变绿。
